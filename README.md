# Tasks

A calm, clinical task and project manager.

```bash
pnpm install
cp .env.example .env.local
pnpm dev
```

1. Run `supabase/pm-setup.sql` once in the Supabase SQL editor.
2. Set `NEXT_PUBLIC_SUPABASE_URL` and `SUPABASE_SERVICE_ROLE_KEY` (server only).

See `CLAUDE.md` for design rules and architecture.
